# tools

- `fetch-spike-assets.mjs` (REL-01): tải lại `public/spike-assets/` (không commit): ảnh mẫu công khai của MediaPipe dùng cho e2e cục bộ và spike (`face.png` = business-person.png, `hands.jpg` = woman_hands.jpg, `thumbs_up.jpg`, `pointing_up.jpg`; sha256 pin trong script), `--all` thêm `mobilenetv2-12.onnx` của ONNX model zoo cho S6; WebM cho S4, S5 tạo bằng `tools/spikes/make-webm.mjs`. Chạy: `npm run spikes:fetch`.
- `fetch-models.mjs` (SETUP-00, REL-01): tải model `.task`, copy wasm của `@mediapipe/tasks-vision` (chỉ `wasm.files`: loader module + SIMD) và loader ORT (`ort.files`: cặp asyncify và jsep) vào `public/models` theo `public/models/models.json`, xóa file không còn trong manifest, sinh model stub. Chạy: `npm run models:fetch`.
- `spikes/` (SPIKE-00): trang spike `s1.html` đến `s6.html` chạy trên dev server; `mp.worker.ts` và `mp.classic.worker.js` là hai kiểu worker MediaPipe đã thử; `make-webm.mjs` tạo WebM mẫu; `run-spike.mjs` chạy một trang trong Chromium headless và ghi `docs/spikes/raw/`. Kết quả: `docs/spikes.md`.
- `make_test_clips.py` (TEST-00): tạo clip y4m tổng hợp cho Playwright.
- `benchmark-report.mjs` (PERF-01, QA-02): đọc `reports/soak-samples.json` (soak) rồi ghi mục "Kết quả soak" của `docs/benchmark.md`; gộp `reports/bench-<project>.json` của `npm run test:bench` (`tests/bench/bench.spec.ts`, `playwright.bench.config.ts`: Chromium headless shell, Chrome và Edge cài trên máy, Firefox và WebKit khi đã cài cho Playwright) vào `docs/benchmark-matrix.json` rồi ghi mục "Ma trận thiết bị và trình duyệt" (môi trường, số đo, tham số chốt so với số đo). Chạy: `npm run test:soak` và/hoặc `npm run test:bench` rồi `npm run bench:report`.
- `test-report.mjs` (QA-01, REL-01): đọc `reports/unit.json` (Vitest), `reports/e2e.json` (Playwright) và `reports/deploy.json` nếu có (`npm run test:deploy`, mục riêng với tên project) rồi ghi mục "Kết quả lần chạy" của `docs/test-report-mask.md`. Chạy: `npm run test:report` (chạy test rồi sinh) hoặc `npm run test:report:write`.
- `screenshots.mjs` (UX-02): `npm run screenshots` khởi động Vite tại chỗ (cổng 5175), chụp màn hình bắt đầu ở 1280 × 720, 1920 × 1080, 390 × 844 và sân khấu với lớp hướng dẫn (nguồn tổng hợp) bằng Chromium của Playwright vào `docs/screenshots/`.
- `dataset/` (CLS-01, D-043): `common.py` (đọc dataset, `check` cấu trúc và frame gốc), `label.py` (list, set, from-dirs, check, csv), `split.py` (chia theo subjectId, kiểm rò rỉ), `stats.py` (bảng vào `docs/dataset.md`), `test_dataset.py` (`python -m unittest discover -s tools/dataset`). Chỉ thư viện chuẩn Python 3.
- `train/` (CLS-02, D-044): `dataset.py` (Dataset từ CLS-01 với augment mô phỏng đường chạy), `train.py` (MobileNetV3-small hay EfficientNet-B0, 2 lớp), `export_onnx.py` (opset 17, input cố định), `check_onnx.py` (so torch với onnxruntime), `eval.py` (metric mục 7.3 vào `docs/classifier-report.md`), `metrics.py` + `test_metrics.py` (thuần, `python -m unittest discover -s tools/train`); cần `requirements.txt` (torch, torchvision, Pillow, numpy, onnx, onnxruntime).
- `make-stub-classifier.mjs` (CLS-02): sinh `public/models/classifier-stub.onnx` (protobuf ONNX mã hóa tay, không phụ thuộc gói onnx); `models:fetch` gọi sẵn.
