# tools

- `fetch-spike-assets.mjs` (REL-01): re-downloads `public/spike-assets/` (not committed): MediaPipe public sample images used for local e2e and spikes (`face.png` = business-person.png, `hands.jpg` = woman_hands.jpg, `thumbs_up.jpg`, `pointing_up.jpg`; sha256 pinned in the script), `--all` also fetches `mobilenetv2-12.onnx` from the ONNX model zoo for S6; the WebM files for S4 and S5 are generated by `tools/spikes/make-webm.mjs`. Run: `npm run spikes:fetch`.
- `fetch-models.mjs` (SETUP-00, REL-01): downloads the `.task` models, copies the `@mediapipe/tasks-vision` wasm (only `wasm.files`: module loader + SIMD) and the ORT loader (`ort.files`: the asyncify and jsep pair) into `public/models` according to `public/models/models.json`, deletes files no longer in the manifest, generates the stub model. Run: `npm run models:fetch`.
- `spikes/` (SPIKE-00): spike pages `s1.html` to `s6.html` run on the dev server; `mp.worker.ts` and `mp.classic.worker.js` are the two MediaPipe worker styles that were tried; `make-webm.mjs` generates the sample WebM; `run-spike.mjs` runs one page in headless Chromium and writes `docs/spikes/raw/`. Results: `docs/spikes.md`.
- `make_test_clips.py` (TEST-00): generates synthetic y4m clips for Playwright.
- `benchmark-report.mjs` (PERF-01, QA-02): reads `reports/soak-samples.json` (soak) and writes the "Soak results" section of `docs/benchmark.md`; merges the `reports/bench-<project>.json` files from `npm run test:bench` (`tests/bench/bench.spec.ts`, `playwright.bench.config.ts`: Chromium headless shell, Chrome and Edge installed on the machine, Firefox and WebKit when installed for Playwright) into `docs/benchmark-matrix.json` and writes the "Device and browser matrix" section (environment, measurements, locked parameters versus measurements). Run: `npm run test:soak` and/or `npm run test:bench`, then `npm run bench:report`.
- `test-report.mjs` (QA-01, REL-01): reads `reports/unit.json` (Vitest), `reports/e2e.json` (Playwright) and `reports/deploy.json` if present (`npm run test:deploy`, a separate section with the project name) and writes the "Run results" section of `docs/test-report-mask.md`. Run: `npm run test:report` (runs the tests, then generates) or `npm run test:report:write`.
- `probe-fingers.mjs` (ROI-04, D-055): `node tools/probe-fingers.mjs [baseUrl] [--json out.json] [image ...]` runs the hand landmarker in a page of the dev server on the spike images (default `hands.jpg`, `pointing_up.jpg`, `thumbs_up.jpg`) and prints, per hand and finger, the model's `visibility` (always 0), the wrist→tip / wrist→PIP ratio in 2D and on the world landmarks, the PIP and DIP angles, the thumb abduction ratio and whether the tip lies inside the palm polygon; `--json` dumps the 2D and world landmarks of every hand as unit-test fixtures. Not part of CI; the numbers of 2026-09-21 are in the ROI-04 package.
- `measure-logo.mjs` (BRAND-01, D-056): `node tools/measure-logo.mjs <logo.png> [mockup.png]` decodes a raster export of the campaign logo with a canvas in Chromium headless and prints its size, ink bounding box, the two ink colors, the horizontal and vertical frame strokes (long straight navy runs) and, with a mock-up image, the bounding box of its black blocks and the grid pitch; a cross-check of the geometry that `src/core/brandLogo.ts` takes from the bundled SVG. Not part of CI; the numbers of 2026-09-21 are in the BRAND-01 package.
- `measure-loop.mjs` (PERF-02): `node tools/measure-loop.mjs [baseUrl] [seconds] [label]` drives a running dev server (default http://localhost:5173) with Chrome headless via `channel` and records, for five states of the synthetic source (region closed, mouse window, orbiting fake hands, still fake hands, closed again), the main-thread and script share from CDP `Performance.getMetrics`, output fps, `paints`/`frames`, render and tick p50/p95. Not part of CI; the numbers of 2026-09-20 are in the PERF-02 implementation note.
- `screenshots.mjs` (UX-02): `npm run screenshots` starts Vite in place (port 5175) and captures the landing screen at 1280 × 720, 1920 × 1080, 390 × 844 and the stage with the guidance layer (synthetic source) using Playwright's Chromium into `docs/screenshots/`.
- `dataset/` (CLS-01, D-043): `common.py` (reads the dataset, `check` for structure and raw frames), `label.py` (list, set, from-dirs, check, csv), `split.py` (splits by subjectId, checks for leakage), `stats.py` (tables into `docs/dataset.md`), `test_dataset.py` (`python -m unittest discover -s tools/dataset`). Python 3 standard library only.
- `train/` (CLS-02, D-044): `dataset.py` (Dataset from CLS-01 with augmentation that simulates the runtime path), `train.py` (MobileNetV3-small or EfficientNet-B0, 2 classes), `export_onnx.py` (opset 17, fixed input), `check_onnx.py` (compares torch with onnxruntime), `eval.py` (section 7.3 metrics into `docs/classifier-report.md`), `metrics.py` + `test_metrics.py` (pure, `python -m unittest discover -s tools/train`); requires `requirements.txt` (torch, torchvision, Pillow, numpy, onnx, onnxruntime).
- `make-stub-classifier.mjs` (CLS-02): generates `public/models/classifier-stub.onnx` (hand-encoded ONNX protobuf, no dependency on the onnx package); `models:fetch` already calls it.
